# Revit MCP Codex Plugin

Codex plugin for Autodesk Revit 2024 on Windows.

## Install

```text
/plugin marketplace add BhaveshY/revit-mcp-codex-plugin
/plugin install revit-mcp-cowork@revit-mcp-codex-plugin
```

## Use

- Install the Revit 2024-side addin first.
- Make sure Node.js 18+ is available so `npx -y mcp-server-for-revit` can start.
- Keep the Revit model open before using the skills.

## Prerequisites

- Autodesk Revit 2024 on Windows.
- The RevitMCP addin installed under `%AppData%\Autodesk\Revit\Addins\2024\`.
- Node.js 18+.
